# Projeto TodoList Pro

## O que foi criado

- Página de login com cadastro e recuperação de senha
- Área principal de produtividade com agenda e lista de tarefas
- Persistência local em navegador com `localStorage`
- Organização por data, prioridade e status da tarefa

## Como executar

1. Abra o arquivo `index.html` no navegador, ou
2. Execute em um terminal:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Funcionalidades

- Criar conta com senha e pergunta de recuperação
- Fazer login com e-mail e senha
- Recuperar aceso por pergunta secreta
- Adicionar tarefas com data e prioridade
- Marcar tarefas como concluídas
- Remover tarefas
- Visualizar agenda por mês e por dia selecionado
- Dados salvos no navegador

## Observações

Este projeto foi implementado como uma aplicação front-end simples, ideal para demonstrar o fluxo de autenticação e organização de tarefas sem dependências externas.
